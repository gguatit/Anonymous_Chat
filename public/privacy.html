개인정보 처리방침

채팅으로 돌아가기

Anonymous Chat(이하 "서비스")는 익명 채팅 기능 제공을 위해 최소한의 정보를 처리합니다. 본 방침은 서비스 내에서 처리되는 정보의 종류, 목적, 보관 기간, 이용자의 권리를 안내합니다.

시행일: 2026-04-09

1. 처리하는 정보 항목

  • 접속 정보: IP 주소, 국가 코드, User-Agent
  • 세션 식별자: sessionId (로컬 생성 식별자)
  • 이용자 입력 정보: 닉네임, 채팅 메시지 내용, 파일 첨부 메타데이터(URL/파일명/용량/유형)
  • 운영/보안 정보: 차단 정보(IP, sessionId), 감사 로그, 오류 로그
  • 알림 정보: 웹 푸시 구독 정보(endpoint, key) 또는 FCM 토큰
  • 브라우저 로컬 저장소 정보: chatSessionId, chatNickname, admin_token 등

2. 정보 처리 목적

  • 실시간 채팅 제공 및 세션 유지
  • 스팸/남용 방지, 차단 정책 적용, 보안 사고 대응
  • 서비스 장애 분석 및 오류 복구
  • 관리자 인증 및 감사 추적
  • 사용자 선택 시 푸시 알림 제공

3. 보관 기간

항목 보관 기간 비고
채팅 메시지 최대 12시간 주기적 정리 및 메시지 처리 시점 정리
관리자 감사 로그 최대 30일 KV TTL 적용
푸시 구독 정보 최대 30일 KV TTL 적용
로그인 시도 제한 데이터 최대 10분 브루트포스 방지 목적
무효화 토큰 정보 최대 2시간 관리자 세션 보안 목적
오류 로그 최대 100건 링 버퍼 형태로 순환 보관
로컬스토리지 데이터 이용자 삭제 전까지 브라우저 단말 내 저장

4. 제3자 제공 및 외부 서비스

  • 파일 업로드 기능 사용 시 파일 저장/전송을 위해 외부 파일 API(file.xeon.kr)를 사용할 수 있습니다.
  • 비밀 메시지 기능 사용 시 Dead Drop API(api.kalpha.kr)를 사용할 수 있습니다.
  • 푸시 알림 기능 사용 시 브라우저 푸시 인프라 또는 FCM 연동이 사용될 수 있습니다.
  • 서비스 인프라 운영을 위해 Cloudflare 플랫폼을 사용합니다.

5. 이용자 권리

  • 브라우저 로컬스토리지 데이터는 브라우저 설정에서 직접 삭제할 수 있습니다.
  • 푸시 알림 구독은 서비스 내 알림 토글 또는 브라우저 권한 설정에서 해제할 수 있습니다.
  • 문의 시 합리적인 범위에서 정보 처리 관련 안내를 받을 수 있습니다.
