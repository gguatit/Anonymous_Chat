익명채팅 이용방법

빠른 시작

별도의 회원가입 없이 바로 채팅에 참여할 수 있습니다. 페이지에 접속하면 자동으로 익명 세션이 생성되며, 브라우저에 세션 정보가 저장되어 같은 브라우저에서는 닉네임 등 설정이 유지됩니다.

회원가입 불필요 익명 보장 실시간 채팅

채널 (Channel)

  • • 채팅창의 빈 공간을 우클릭하면 "채널 추가"와 "채널 참가" 메뉴가 표시됩니다.
  • • 채널 추가: 원하는 이름(예: kalpha)을 입력하면 새로운 채널이 생성되고 자동으로 입장합니다. 같은 이름의 채널은 중복 생성할 수 없습니다.
  • • 채널 참가: 이미 존재하는 채널의 이름을 입력하면 해당 채널로 입장합니다.
  • • 채널에 입장하면 헤더에 #채널명 배지가 표시되며, "메인으로" 버튼을 누른 메인 채팅방으로 돌아갈 수 있습니다.
  • • 채널 안에 사람이 없는 상태로 10분이 지나면 자동으로 삭제됩니다.
  • • 채널 내에서도 메인 채팅방과 동일하게 메시지, 파일, 답장 등 모든 기능을 사용할 수 있습니다. 다만 채널 메시지는 푸시 알림이 발송되지 않습니다.

기본 채팅

  • • 메시지 입력창에 내용을 입력하고 Enter를 누르면 전송됩니다.
  • • 줄바꿈이 필요하면 Shift + Enter를 사용하세요.
  • • 메시지는 최대 7500자까지 입력할 수 있으며, 실시간으로 글자 수가 표시됩니다.
  • • Rate Limiting: 초당 1개, 분당 30개의 메시지 전송 제한이 있습니다. 제한을 초과하면 경고 메시지가 표시됩니다.
  • • 메시지는 전송 후 12시간이 지나면 자동으로 삭제됩니다. 서버에 장기간 저장되지 않습니다.
  • • 접속 시 최근 50개의 메시지 히스토리를 배치로 받아 빠르게 로딩됩니다. (기존 개별 로딩 대비 25배 성능 향상)
  • • 메시지가 전달된 사용자 수가 표시되어, 현재 몇 명이 내 메시지를 받았는지 확인할 수 있습니다.

메시지 포맷팅 (마크다운)

메시지에 다양한 서식을 적용할 수 있습니다.

**볼드** 볼드
*이탤릭* 이탤릭
~~취소선~~ 취소선
`코드` 코드
> 인용구 인용구
[텍스트](URL) 텍스트

URL은 자동으로 링크로 변환되며, 이미지 URL(jpg, jpeg, png, gif, webp, svg)은 인라인 미리보기가 표시됩니다.

코드 블록

  • • 세 개의 백틱(```)으로 코드 블록을 만들 수 있습니다. 언어를 지정하면 해당 언어의 구문 강조가 적용됩니다.
  • • 언어를 지정하지 않아도 휴리스틱 엔진이 15개 이상의 언어(JavaScript, Python, C++, Go, Rust, SQL, HTML, Bash, JSON 등)를 자동으로 판별하여 하이라이팅을 적용합니다.
  • • 코드 블록 헤더에는 감지된 언어명이 표시되며, 우측 상단의 복사 버튼으로 코드를 클립보드에 복사할 수 있습니다.

닉네임 설정

  • • 화면 우측 상단의 닉네임 입력창에서 원하는 이름을 설정할 수 있습니다. 최대 12자까지 입력 가능합니다.
  • • 닉네임은 localStorage에 저장되어 세션이 유지되는 동안 계속 사용됩니다.
  • • 자물쇠 아이콘으로 닉네임을 잠글 수 있습니다. 잠금 해제 시 사칭 방지를 위한 면책 모달이 표시되며, "다시 보지 않기"를 체크하면 이후에는 모달이 뜨지 않습니다.
  • • 설정하지 않으면 자동으로 "익명"으로 표시됩니다.

파일 및 이미지 공유

  • • 이미지, 동영상, 오디오, 일반 파일을 업로드할 수 있습니다. 파일당 최대 100MB, 한 번에 최대 10개의 파일을 업로드할 수 있습니다.
  • • 파일을 채팅창에 드래그 앤 드롭하거나, 클립보드에서 Ctrl+V로 이미지를 붙여넣을 수 있습니다.
  • • 이미지와 비디오는 채팅 내에서 바로 미리보기가 가능하며, 여러 이미지를 업로드하면 갤러리 형태로 표시됩니다. 이미지를 클릭하면 라이트박스가 열려 확대해서 볼 수 있습니다.
  • • 업로드 진행률이 실시간으로 표시되며, 업로드 중에는 전송 버튼이 비활성화됩니다. 업로드 취소도 가능합니다.

메시지 답장

  • • 답장하고 싶은 메시지를 우클릭하거나 길게 누르세요(모바일). 컨텍스트 메뉴에서 "답장"을 선택하면 됩니다.
  • • 답장 입력 중에는 원본 메시지 미리보기가 입력창 위에 표시되며, X 버튼으로 답장을 취소할 수 있습니다.
  • • 전송된 답장 메시지에는 원본 메시지 내용이 50자로 잘려서 미리보기로 표시됩니다. 미리보기를 클릭하면 원본 메시지로 스크롤 이동합니다.

메시지 수정 및 삭제

  • • 본인이 보낸 메시지는 전송 후 10분 이내에만 수정/삭제할 수 있습니다.
  • • 메시지를 우클릭/길게 눌러 컨텍스트 메뉴에서 "수정" 또는 "삭제"를 선택하세요.
  • • 수정된 메시지에는 (수정됨) 표시가 붙으며, 삭제된 메시지는 모든 사용자에게 실시간으로 반영됩니다.

테마 변경

  • • 채팅창 상단의 메뉴 버튼(≡)을 눌러 왼쪽 패널을 열면 테마 섹션이 표시됩니다.
  • • 다크, 라이트, 미드나잇, 오션, 포레스트, 애미시스트, 선셋, 사쿠라 등 8가지 테마 중 선택할 수 있습니다.
  • • 선택한 테마는 브라우저에 자동 저장되며, 채팅, 공지사항, 도움말 페이지 모두에 적용됩니다.

메시지 반응 (Reaction)

  • • 메시지를 더블클릭하면 자동으로 👍 반응이 추가됩니다. 한 번 더 더블클릭하면 제거됩니다.
  • • 메시지를 우클릭하고 "반응 추가"를 선택하면 👍❤️😂😮😢😡 6가지 이모지 중 원하는 반응을 선택할 수 있습니다.
  • • 동일한 반응을 다시 클릭하면 토글(추가/제거)됩니다. 내가 반응한 이모지는 푸른색으로 하이라이트됩니다.
  • • 반응은 실시간으로 모든 사용자에게 동기화되며, 반응 수가 이모지 옆에 표시됩니다.

비밀 메시지 (Dead Drop)

  • • 입력창 옆의 자물쇠 버튼을 눌러 비밀 메시지를 작성할 수 있습니다.
  • • 비밀 메시지는 1회만 열람 가능하며, 열람 후 즉시 서버에서 삭제됩니다. 링크를 받은 사람만 볼 수 있습니다.
  • • 전송 후 생성된 링크를 복사해서 특정 상대에게만 공유할 수 있습니다. 링크를 가진 사람은 누구나 1회 열람할 수 있습니다.

메시지 검색

  • • 헤더의 검색 버튼이나 Ctrl+F를 눌러 검색 오버레이를 열 수 있습니다. ESC를 누르면 닫힙니다.
  • • 최근 12시간 이내의 모든 메시지에서 내용, 닉네임, 파일명을 검색할 수 있습니다. 공백으로 구분된 여러 키워드는 AND 조건으로 검색됩니다.
  • • 태그 필터링: 검색창 상단의 태그 버튼이나 검색어에 직접 입력하여 유형별로 필터링할 수 있습니다.
  • - #images — 이미지가 포함된 메시지만 검색
  • - #files — 파일이 포함된 메시지만 검색
  • - #code — 코드 블록이 포함된 메시지만 검색
  • - #url — URL이 포함된 메시지만 검색
  • • 검색 결과를 클릭하면 해당 메시지로 자동 스크롤 이동하며, 메시지가 하이라이트됩니다.

공지사항

  • • 새로운 공지가 등록되면 채팅 상단에 노란색 배너로 표시됩니다.
  • • 헤더의 "공지" 버튼을 누르면 공지사항 페이지로 이동하여 과거 공지 전체를 열람할 수 있습니다. 버튼 옆의 빨간 점은 읽지 않은 새 공지가 있음을 알립니다.
  • • 공지 읽음 여부는 localStorage에 저장되며, 새로운 공지가 올라오면 자동으로 뱃지가 표시됩니다.

알림 설정

  • • 브라우저 푸시 알림을 받으려면 상단의 종 아이콘을 눌러 구독하세요.
  • • PWA(Progressive Web App)로 홈 화면에 추가하면 앱처럼 사용할 수 있으며, Android에서는 완전히 종료된 상태에서도 푸시 알림 수신이 가능합니다.
  • • 페이지가 백그라운드에 있을 때 새 메시지가 오면 브라우저 타이틀에 미읽음 메시지 수가 표시됩니다.
  • • 현재 일부 플랫폼에서 푸시 알림 기능이 올바르게 작동하지 않을 수 있습니다. 코드는 구현되어 있으나 실제 환경에서 알림이 전송되지 않을 수 있습니다.

보안 헤더 분석

  • • 채팅 내 HTTP/HTTPS URL 옆에 보안 분석 아이콘(방패 모양)이 표시됩니다.
  • • 아이콘을 클릭하면 Kalpha Security API(외부 보안 분석 API)를 통해 해당 사이트의 보안 헤더를 분석한 결과가 모달로 표시됩니다.
  • • 분석 결과에는 점수, 등급, 프로그레스 바, 헤더 설정 상태, 상세 분석 항목이 포함됩니다.
  • • 해당 API는 개발 중인 기능으로, 분석 결과의 신뢰성은 참고용으로만 사용하세요.

보안 및 익명성

  • • 모든 메시지는 익명으로 전송되며, 개인정보를 수집하지 않습니다.
  • • 봇 및 악성 접근을 필터링하는 보안 검증을 거친 후 채팅에 참여할 수 있습니다.
  • • 과도한 메시지 전송을 방지하기 위해 전송 속도 제한이 적용되어 있습니다.
  • • 모든 입력은 XSS 방지를 위한 이스케이프 처리가 적용됩니다.
  • • 프로덕션 환경에서는 HTTP 요청을 HTTPS로 자동 전환합니다.

연결 상태 및 재연결

  • • 화면 상단에서 현재 연결 상태를 확인할 수 있습니다: 연결 중(노란색), 연결됨(초록색), 연결 끊김(빨간색), 재연결 중(주황색), 오류 발생(빨간색).
  • • 연결이 끊어지면 자동으로 재연결을 시도합니다. 최대 10회까지 재시도하며, 간격이 점점 늘어나는 방식으로 시도합니다.
  • • 페이지가 백그라운드(다른 탭)에 있다가 다시 활성화되면, 연결이 끊어져 있을 경우 자동으로 재연결합니다.
  • • 타자 표시기: 다른 사용자가 입력 중일 때 "익명이 입력 중..." 메시지가 표시됩니다.

AI 대화 요약

사용 가능한 명령어

/summary 최근 대화를 3~5문장으로 종합 요약합니다. (기본 모드)
/topic 대화에서 다뤄진 주제들을 글머리 형식으로 정리하고, 각 주제별 참여자 수를 표시합니다.
/mood 대화의 전체적인 분위기와 감정 톤을 분석합니다. 유머/진지함/긍정/부정 수치와 대표 발언을 보여줍니다.
/conflict 대화 속 의견 충돌이나 논쟁 지점을 중립적으로 정리합니다. 논쟁이 없으면 없다고 표시합니다.

작동 방식

  • 최근 50개의 메시지를 수집 (AI 요약 메시지는 제외)
  • 발신자 정보(sessionId)를 제거한 후 AI 모델에 전달
  • 요약 결과는 모든 사용자에게 공유됩니다

제한 사항

  • 15초에 1회만 요청 가능 (서버 과부하 방지)
  • 충분한 대화가 없으면 요약 품질이 낮을 수 있음
  • AI 답변은 항상 정확하지 않을 수 있음

알려진 제한사항

  • • 푸시 알림 오류: 일부 플랫폼(특히 iOS Safari)에서 푸시 알림이 정상 작동하지 않을 수 있습니다.
  • • 무한 스크롤 미지원: 접속 시 최근 50개 메시지만 로드되며, 이전 메시지는 검색을 통해 찾을 수 있습니다.
  • • Ctrl+Enter 미지원: 메시지 전송은 Enter 키만 지원합니다.
