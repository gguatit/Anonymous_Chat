익명채팅 이용방법

🚀 빠른 시작

별도의 회원가입 없이 바로 채팅에 참여할 수 있습니다. 페이지에 접속하면 자동으로 익명 세션이 생성되며, 닉네임을 설정하면 나를 식별하는 데 도움이 됩니다.

회원가입 불필요 익명 보장 실시간 채팅

💬 기본 채팅

  • • 메시지 입력창에 내용을 입력하고 Enter를 누륩면 전송됩니다.
  • • 줄바꿈이 필요하면 Shift + Enter를 사용하세요.
  • • 초당 1개, 분당 30개의 메시지 전송 제한이 있습니다.
  • • 메시지는 12시간 후 자동으로 삭제됩니다.

✨ 메시지 포맷팅 (마크다운)

메시지에 다양한 서식을 적용할 수 있습니다.

**볼드** 볼드
*이탤릭* 이탤릭
~~취소선~~ 취소선
`코드` 코드
> 인용구 인용구
[링크](URL) 링크

👤 닉네임 설정

  • • 화면 우측 상단의 닉네임 입력창에서 원하는 이름을 설정할 수 있습니다.
  • • 닉네임은 세션 동안 유지되며, 자물쇠 아이콘으로 잠글 수 있습니다.
  • • 설정하지 않으면 자동으로 "익명"으로 표시됩니다.

📎 파일 및 이미지 공유

  • • 이미지, 동영상, 오디오, 일반 파일을 업로드할 수 있습니다. (최대 100MB)
  • • 파일을 채팅창에 드래그 앤 드롭하거나, 클립보드에서 Ctrl+V로 붙여넣기 할 수 있습니다.
  • • 이미지와 비디오는 채팅 내에서 바로 미리보기가 가능합니다.

💻 코드 블록

  • • 세 개의 백틱(```)으로 코드 블록을 만들 수 있습니다.
  • • 언어를 자동으로 감지하여 구문 강조(Syntax Highlighting)를 적용합니다.
  • • 코드 블록 우측 상단의 복사 버튼으로 코드를 클립보드에 복사할 수 있습니다.

↩️ 메시지 답장

  • • 답장하고 싶은 메시지를 우클릭하거나 길게 누르세요(모바일).
  • • "답장"을 선택하면 해당 메시지에 대한 답장이 작성됩니다.
  • • 원본 메시지 내용이 50자로 미리보기되어 표시됩니다.

✏️ 메시지 수정 및 삭제

  • • 본인이 보낸 메시지는 전송 후 10분 이내에만 수정/삭제할 수 있습니다.
  • • 메시지를 우클릭/길게 눌러 "수정" 또는 "삭제"를 선택하세요.
  • • 수정된 메시지에는 (수정됨) 표시가 붙습니다.

🔒 비밀 메시지 (Dead Drop)

  • • 입력창 옆의 🔒 버튼을 눌러 비밀 메시지를 작성할 수 있습니다.
  • • 비밀 메시지는 1회만 열람 가능하며, 열람 후 즉시 삭제됩니다.
  • • 링크를 복사해서 특정 상대에게만 공유할 수 있습니다.

🔍 메시지 검색

  • • 헤더의 검색 버튼이나 Ctrl+F를 눌러 검색할 수 있습니다.
  • • 키워드로 메시지 내용, 닉네임, 파일명을 검색할 수 있습니다.
  • • 태그 검색: #images (이미지), #files (파일), #code (코드)로 유형별 필터링이 가능합니다.

📢 공지사항

  • • 헤더의 "📢 공지" 버튼을 눌러 과거 공지사항을 확인할 수 있습니다.
  • • 새로운 공지가 등록되면 채팅 상단에 표시됩니다.

🔔 알림 설정

  • • 브라우저 푸시 알림을 받으려면 상단의 종 아이콘을 눌러 구독하세요.
  • • PWA(홈 화면에 추가)로 설치하면 앱처럼 사용할 수 있습니다.
  • ⚠️ 현재 일부 플랫폼에서 푸시 알림이 정상 작동하지 않을 수 있습니다.

🛡️ 보안 및 익명성

  • • 모든 메시지는 익명으로 전송되며, 개인정보를 수집하지 않습니다.
  • • URL 옆의 🛡️ 아이콘을 눌러 해당 사이트의 보안 헤더를 분석할 수 있습니다.
  • • 메시지는 12시간 후 자동 삭제되며, 서버에 장기간 저장되지 않습니다.
